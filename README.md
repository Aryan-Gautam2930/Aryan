# Record System for CHW

A responsive patient visit log and follow-up reminder application for Community Health Workers.

## Development

This project uses React, TypeScript, TanStack Start, Vite, and Tailwind CSS.

```bash
npm install
npm run dev
```

## Important

Do not commit secrets or real patient records. Configure authentication and database access controls before using real patient information. Browser notifications and speech depend on browser/device support.

The source was exported from the CHW CareConnect Lovable project. See the Lovable editor for ongoing development: https://lovable.dev/projects/6ae4f28d-34e8-45fc-89d2-162ebccbcbad
